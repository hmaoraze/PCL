# PCL 社区修改版 2.99.0.0

> 本版本由社区基于 PCL 官方公开源码修改，**并非 PCL 官方发布**，与 PCL 作者及官方团队无关。
> 请从本页面下载，不要使用第三方转载的安装包。

---

## 这个版本做了什么

官方 2.99.0.0 移除了 MC 下载功能，本版本将其恢复，并补充了明确的来源与免责说明。

**恢复的功能**

- 下载页可正常加载 Minecraft 版本列表，可安装原版与各类加载器
- 整合包安装恢复：CurseForge / Modrinth / MCBBS / HMCL / MMC / 压缩包
- 版本修改页恢复「Minecraft 版本」卡片，可修改、添加、移除已安装版本
- 拖拽压缩包到窗口可直接安装整合包

**新增的说明**

- 启动弹窗新增社区修改版声明：红色标注、写明上游提交、提交号可点击跳转 GitHub
- 弹窗中保留官方原有的「无法使用的特性」说明，样式不变
- 窗口标题、关于页面、版本号统一标注为「PCL 社区修改版」，避免与官方包混淆
- 安全加固：自定义主页触发的「执行命令 / 打开文件」不再支持「今后不再要求确认」，且禁止通过自定义事件改写该开关
- 关于页「检查更新」改为打开发布页，并提示「请自行核对是否有新版本」

**未改动的部分**

除上述内容外，UI、逻辑、依赖均与上游提交保持一致，未加入任何额外功能、统计上报或网络请求。

## 已知限制

- **无自动更新**：开源版的更新模块为空实现，新版本需手动下载替换
- **无正版登录 / CurseForge**：需要自行向微软申请 Client ID、向 CurseForge 申请 API Key，填入 `Modules/ModSecret.vb` 后重新编译
- **主题切换、百宝箱不可用**：这两项属于官方赞助/开发者向功能
- 若从旧版本覆盖升级，建议先关闭正在运行的 PCL，否则文件会被占用
